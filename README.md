[Live demo](https://noexperiencecvbuilder.netlify.app)

Functionalitati:
 - Drag & Drop pe componente React
 - Zustand / Redux pentru state management atomic si functionalitate de Undo.
 - CV-as-Code (Editarea CV-ului se poate face ca text in limbaj YAML usor lizibil).
 - Debounce pentru live preview la modificare continut cod YAML in editor.
 - Monaco-editor integrat cu React in pagina. Face sintax highlight automat. Se foloseste un schema.json pentru validare field-uri custom.
 - Customazibilitate pe tematica
 - Git versioning (implementare automata cu git)
 - Link analytics
 - Cover letter generator
 - PDF vectorizat, JSON/TXT rendering/export
 - AI Agent chatbot integrat cu elementele din website
 - Rate limiter pentru AI care va folosi API-ul meu personal de gemini
 - Diffing & stream pe raspunsul AI-ului si optiune de undo la modificari
 - Generare link public securizat de vizualizare CV
 - Smart Parsing CV pentru import
 - WYSIWYG preview
 - Auto-translate
 - Implementare metoda cumparare coins AI prin Stripe (just for fun)
